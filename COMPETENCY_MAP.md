# PromptLab and TraceLens: same competencies, different domain

Choose one track. TraceLens is an independent, more challenging alternative, not extra credit or a second required project. PromptLab remains the video walkthrough project. All students complete the common Module 1 TokenScope activity.

Same standard does not mean identical code or effort: TraceLens has more domain logic and an additional inherited defect. Neither track gets bonus credit. Both require 22 Met decisions, the same five MUST PASS gates, authentic history, the 80% threshold, two features, reproducible full-stack behavior and the same defense format. The same final-review/attempt policy applies; there are no weekly capstone uploads.

Public starter checks are learning aids, not a criterion count or complete grader. The assessor applies the same quality bar to learner-authored tests and verifies project-specific contracts. For TraceLens, either feature may be first and any documented valid project-deletion strategy is accepted. Do not impose a hidden feature order, score range, database, paid host or live-model integration requirement.
