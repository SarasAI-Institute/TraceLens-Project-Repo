# Module 6 - Delivery & Recorded Defense

C3 - End-to-End AI-Assisted Application Delivery. **C3.6-C3.8 | Completes C3 when all eight criteria are Met.**

Defend your own final TraceLens code, decisions and use of AI. This module adds no new feature.

This is the optional TraceLens capstone track. Follow PromptLab's demonstrated methods independently; no TraceLens walkthrough is required. Continue your own repository rather than restarting from another starter.

## Work and evidence

1. Supply your final repository link/access, exact commit, run/deployment instructions and accumulated evidence.

2. Receive an instructor-selected backend function and React component from that commit; do not substitute your own selections.

3. Record 12-20 continuous screen/audio minutes within 48 hours of prompt issue, with code visible and no cuts or another person assisting.

4. Explain both selections, trace a complete request, defend a decision and show traceable AI override/error/cost evidence.

5. Answer up to three written clarification questions within two business days if requested. Fresh code is selected for re-attempts.

## Task detail

Finalize EVIDENCE.md and confirm reviewer access before submitting. Preserve the selected final commit while preparing the defense; record any instructor-permitted revision explicitly.

The instructor selects one backend function and one React component. Explain inputs, outputs, errors, structure and what would break if the named part were removed. You may read code. Explain, rather than merely reading comments aloud.

Trace one user action through the actual UI event, API client, handler, storage, response and rendered result, naming source components. Defend one real design decision. Discuss an AI suggestion you overrode/rejected and a concrete wrong or unhelpful output, its cost and your correction, with links to your own prompt log/commits/verification note.

The recording is 12-20 continuous minutes with screen and audio, submitted within 48 hours of prompt issue. No cuts or another person assisting. Cuts require a re-record without consuming an attempt. Up to three written questions can clarify ambiguity within two further business days; they cannot replace an omitted required explanation. Re-attempts use a fresh prompt set with previously unused files. Accommodations may adjust format/time, not the competence requirements.

A working app cannot replace an adequate defense, and a strong defense cannot compensate for an app that does not run. See ASSESSMENT.md for attempts and return policy.
